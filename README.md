# CashBot

Controle financeiro pessoal simples: lançamentos de despesas (manual ou em massa via PDF/OFX/XLSX), cadastro de categorias, resumo com gráficos e painel de patrimônio.

- Frontend: HTML/CSS/JS puro (sem build), em `index.html`.
- Persistência: [Supabase](https://supabase.com) (Postgres + API automática).
- Deploy: [Vercel](https://vercel.com), publicado a partir deste repositório.

Acesse em: https://cashbot-ten.vercel.app
